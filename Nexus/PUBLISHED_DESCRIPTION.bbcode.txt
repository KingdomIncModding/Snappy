[b]Snappy[/b]

Adds three evenly spaced snap positions between each original Kingdom Inc grid position on both axes. A 64-unit interval becomes four 16-unit intervals: 0, 16, 32, 48, 64.

[b]Features[/b]
[list]
[*]Finer node placement and dragging.[/*]
[*]Quarter-grid snapping for purchase/copy previews, pipe bends, decorations and container resizing.[/*]
[*]Preserves native pipe alignment and label offsets.[/*]
[*]Hold Ctrl for the game's usual free placement.[/*]
[*]Enabled automatically; no configuration or hotkey required.[/*]
[/list]
[b]Requirements[/b]
Kingdom Inc (Unity Mono), BepInEx 5 and its bundled Harmony. No other plugin is required.
[url=https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.6]BepInEx official download[/url]

[b]Installation[/b]
1. Install BepInEx 5 for the game if needed.
2. Close Kingdom Inc.
3. Extract the ZIP into the game folder. The plugin belongs at BepInEx/plugins/Snappy/Snappy.dll.
4. Launch the game and move a node.

[b]Updating[/b]
Close the game and replace Snappy.dll, then launch again. No save migration is required.

[b]Compatibility[/b]
The visible background grid keeps its original spacing; extra positions lie between its lines. Node sizes, port counts and minimum container size are unchanged. Existing layouts are not repositioned.

Gallery dots illustrate snapping positions; the mod does not add a marker overlay.

The table lists potential patch overlaps; sharing a method does not by itself establish a conflict.

[b]Removal[/b]
Close the game and delete BepInEx/plugins/Snappy. Existing fine positions survive native save loading without Snappy; further movement uses the normal grid.

[b]Troubleshooting[/b]
Check BepInEx/LogOutput.log for "Snappy ready". Include the game version, plugin version and relevant errors in bug reports.
